Pipeline

4 stages, all local
  1. CaptureRole-aware parsing; code fences preserved byte for byte.
  2. OrganizeRequirements, decisions, tasks, errors and next action extracted.
  3. CompressBalanced, high or full preservation, with labelled token estimates.
  4. ContinueDestination-specific prompt, one click to copy.

Import a capsule

Validation

  • Archive entries are hash-checked against the manifest.
  • Paths are sanitised; traversal outside the data folder is rejected.
  • Format version must be supported by this build.
  • A failed import changes nothing.
